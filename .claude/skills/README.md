# Skills (reference material)

Design and implementation skills for the redesign asked for in `Straight Bussing New Version.txt` (owner, 2026-11-02).
They are third-party, kept as downloaded with their licenses; each folder's SOURCE.md names the repository, path and
commit. Reference only: nothing here is part of the app.

| Folder | What it is for | Source | License |
|---|---|---|---|
| `mobile-ios-design/` | Native iOS design: typography, icons, sheets, gestures (Human Interface Guidelines) | wshobson/agents | MIT |
| `swiftui-expert/` | SwiftUI implementation, animation, performance, accessibility | AvdLee/SwiftUI-Agent-Skill | MIT |
| `mapbox-cartography/` | Map colors, labels, visual hierarchy, readability (applies to the web map's MapLibre style too) | mapbox/mapbox-agent-skills | MIT |
| `mapbox-style-patterns/` | Navigation map styles, markers, layers, night themes | mapbox/mapbox-agent-skills | MIT |
| `impeccable/` | Design critique, consistency, simplification, final polish (web) | pbakaus/impeccable | Apache-2.0 (NOTICE.md kept) |
| `ui-ux-pro-max/` | Design systems, palettes, typography, platform guidance | nextlevelbuilder/ui-ux-pro-max-skill | MIT |
| `frontend-design/` | Intentional aesthetic direction, avoiding generic design | anthropics/skills | see LICENSE.txt |
| `taste-skill/` | Anti-generic visual direction (already here) | third party | MIT |

Recommended for this project (from the owner's file): SwiftUI = mobile-ios-design + swiftui-expert, with impeccable for
critique; the maps = mapbox-cartography + mapbox-style-patterns. Not downloaded: Expo's skills (they are for React
Native / Expo, which Straight Bussing does not use: the iPhone app is SwiftUI and the website plain JavaScript).
